Usage: Type .match in any WhatsApp group

.topic Alias: .topik, .icebreaker

🎲 Gen Z Topic & Dice Roll Icebreaker

Simulates a dice roll to generate fresh, unique, engaging conversation topics tailored to Gen Z communication style (hot takes, icks, dilemmas, pop culture).

How to use:

Usage: Type .topic in the group chat

.wordgame Alias: .tebakkata, .game

🧩 AI Word Guessing Riddle Game

Starts an interactive word riddle game in the group. Any member can guess by typing the answer in chat. Correct answers earn +1 point on the persistent leaderboard.

How to use:

Start: Type .wordgame

Hint / Give Up: Type .wordgame hint or .wordgame giveup

👉 Bot validates guesses in real-time and awards leaderboard points!

🎵 Song Lyric Guessing Game (2016–2026 Hits)

Interactive song guessing game featuring a database of 100 popular chart-topping hits (2016–2026). The bot rolls a 100-sided dice to select a unique song, sends a lyric excerpt, and awards +1 point on the shared leaderboard for correct guesses.

How to use:

Start: Type .guess

Guess: Reply to the bot's message or type the song title in chat

Hint / Give Up: Type .guess hint or .guess giveup

👉 Bot evaluates guesses in real-time and awards +1 point on the leaderboard!

Convert Image to WhatsApp Sticker

Option B: Send a photo with caption .s

👉 Bot immediately sends back the custom WhatsApp sticker.

.delete Alias: .del (Admin Only)

Delete a Member's Message

Reply to any message sent by a group member with .delete. The bot will instantly delete the member's message and clean up the command trigger.

2. Type .delete and send.

👉 Bot deletes the replied message and the command.

.kick @user Group Admins Only

Remove a Member from Group

Remove a disruptive member from the group. You can mention them directly or reply to one of their messages with .kick. Fellow admins and bot are protected.

Option A: Type .kick @user and send.

Option B: Reply to their message with .kick.

👉 Bot kicks the member from the group.

.hidetag [message] Group Admins Only

Broadcast & Tag All Silently

Resend an announcement from the bot account that notifies every single member in the group without cluttering the chat with visible tags.

Option A: Type .hidetag Meeting starts at 5 PM!

Option B: Reply to any text message with .hidetag.

👉 Bot resends message tagging everyone.

.inactive Inactive > 1 Day

Reset the recorded chat count back to 0 for all members in the group, or target a single member by mentioning them.

.block @user Group Admins Only

Block Member (Auto-Delete Messages)

Blocks a member in the group. Whenever a blocked member sends any message, CapyBot will automatically delete it immediately.

How to use:

Option A: Type .block @user

Option B: Reply to a member's message with .block

Option C (List): Type .block to view all blocked members

👉 Bot blocks user and auto-deletes any future messages they post.

.unblock @user Group Admins Only

Unblock Member

Unblocks a previously blocked member so their messages will no longer be deleted by the bot.

How to use:

Usage: Type .unblock @user

👉 Bot removes member from block list and restores normal messaging.

.passive Admin: .passive set [num]

List Passive Group Members

Shows all members in the group who have sent fewer messages than the configured threshold (default: 5 msgs). Admins can update the threshold using .passive set [number].

How to use:

Option A (View): Type .passive

Option B (Set Threshold): Type .passive set 10 (Admins)

👉 Bot lists passive members with their message counts and tags.

.close / .open Group Admins Only

Restrict Group Messaging to Admins Only

Changes WhatsApp group settings so that only administrators can send messages. If regular members attempt to send messages, the bot automatically deletes them and issues a warning. Use .open to unlock messaging for all members.

Lock: Type .close (Admins only)

Unlock: Type .open (All members can send)

👉 Bot updates group permissions and confirms via chat announcement.

Automated Bot Capabilities

Automatic 24/7 moderation and engagement features running in your group

Instagram & TikTok Link Blocker

Detects links from Instagram (posts, reels, stories, profiles) and TikTok (videos, shortlinks). If a non-admin posts a link, the bot deletes it and issues a warning notice. Group Admins are exempt.

"Hi" Auto-Reply

When a member says "Hi", "Hello", or "Hey", the bot replies instantly with a friendly greeting tagging the member. Custom reply templates can be set in the Link Moderation tab.

Real-Time Member Chat Counter

Every message sent in the group is counted and persisted in the local SQLite database. You can view the full Leaderboard on the Dashboard, filter by member, and clear counts individually or reset the whole group.

Web Dashboard & Chat Tools

Safe 15s Auto-Sync (Zero Ban Risk)

The dashboard updates instantly via WebSockets and performs safe local database heartbeat polling. Zero requests are sent to WhatsApp servers during polling, ensuring your account is completely safe from rate-limits or bans.

Multi-User & Multi-Device Architecture

Manage isolated WhatsApp sessions, multiple devices, and custom dashboard themes

Phone + Password Authentication

Create an account with your phone number and secure password. Link settings, group statistics, and live chats are completely isolated per user.

Zero QR Re-Scanning on Relogin

Light & Dark Mode UI
